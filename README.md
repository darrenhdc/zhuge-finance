## 快速结论

1. **数字人民币不是普通第三方支付余额。** 它是法定货币的数字形态，作者反复用“央行—商业银行/运营机构”双层体系解释其发行和流通。
2. **e-CNY 的产品价值在支付轨道。** 支付即结算、双离线、可控匿名、钱包分级、智能合约是作者文章中最常复用的底层能力。
3. **CBETS/数币达是跨境网络。** 它连接境内外参与者，把贸易单据、资金流和信息流放进同一可编程结算流程；其重点不是“快一点”，而是跨境流程重构。
4. **香港稳定币进入持牌与受控互联阶段。** RCHKD 案例显示，机构可以采用区块链账本形式，同时保留许可制节点、白名单、集中私钥和封闭场景。
5. **风险与效率同源。** 支付即结算、低门槛钱包和跨域实时转账既提供便利，也带来跑分、拆分交易、快进快出和跨境规避风险。
6. **反洗钱需要贯穿全生命周期。** 核心是分级 KYC/CDD、钱包限额、名单与制裁筛查、实时行为监测、可疑交易上报、证据保全与用户教育。
7. **Web3 不能与数字人民币混同。** 前者涉及开放网络、资产代币化和可组合协议；e-CNY 是国家信用下的法定货币体系。二者可能在技术组件上重叠，但法律属性和治理结构不同。
